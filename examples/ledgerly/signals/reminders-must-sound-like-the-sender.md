# Payment reminders must sound like the sender, not a robot

> One cold template for every client damages relationships, so customers switch reminders off. Reminders written per client, in their own voice, get used.

## Evidence

- "I turned it off. It sends the same cold text to everyone. A client of five years got the same message as a one-off job." — Dana Holt · Northwind Studio · 2026-09-02 · call `2026-09-02_northwind-studio`
- "If it sounds like a collection agency, the art director will think I am difficult." — Hana Okafor · Hana Okafor · 2026-09-15 · call `2026-09-15_hana-okafor`
- "I can now write one template for regulars and one for slow payers." — Dana Holt · Northwind Studio · 2026-10-20 · call `2026-10-20_northwind-studio`
